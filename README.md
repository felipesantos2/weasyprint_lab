# weasyprint_lab
---
The project explores a simple workflow for generating HTML templates with Jinja2 and converting them into PDF documents using WeasyPrint.
---
### STACK
- Python
- UV
- Jinja2
- WeaseyPrint
- Flask
- Rich CLI
### SETUP
sync dependecies:
```bash
    uv sync
```
run script
```bash
    uv run app.py
```
